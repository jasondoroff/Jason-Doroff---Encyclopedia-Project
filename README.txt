World of Senethis - Interactive Encyclopedia by Jason Doroff

A encyclopedia holding information on a fantasy world.

Has encyclopedia pages on history, characters, and places.
These pages use similar java script to sort, filter, and display the info in collapsible info cards.
History page can sort by alphabetical, and chronological while filtering based on continent.
Character page can sort by alphabetical, and Age while filtering base on game of introduction.
Places page can sort by alphabetical, and population while filtering based on continent.

The Atlas page has a collection of maps for users to browse. The maps are accessed via dynamically created buttons stored in collapsible categories.
The map can be clicked on to expand, then can be zoomed in and out while being panned.

The entire page holds a fantasy/medieval theme with custom UI elements.

Uses:
HTML for sight structure
CSS for visual organization and design
JavaScript for functionality
JavaScript to store the various entries

All assets are included in the files for the program.
Index.html is the homepage for the website.
